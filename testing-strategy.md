# Testing Strategy

Use the following commands to verify the repo locally:

- Formatting:
  `npm run format:check`
- Lint:
  `npm run lint`
- Type checking:
  `npm run typecheck`
- Full tests:
  `npm run test`
- Database migration check:
  `npm run migrate`
- Seed verification:
  `npm run seed`

See [docs/testing-strategy.md](./docs/testing-strategy.md) for the full testing approach and CI gates.
